## Authoritative source decisions already recorded

At the time of this review the bootstrap ruleset contained only five verified mechanics: combat level; melee effective strength; melee max hit; melee accuracy; and the nominal 600 ms logical tick (it has since grown to 53; see [`rulesets/README.md`](../../rulesets/README.md)). Each is pinned to an OSRS Wiki revision in [`rulesets/osrs-f2p-v1/mechanics.json`](../../rulesets/osrs-f2p-v1/mechanics.json).

The F2P PvP techniques page (revision `15270837`) explicitly describes range-to-melee stacking with a rapid shortbow, switching to melee, a 2–3 tile setup, and the aim of same-tick hits. The fast-food page (revision `15264530`) distinguishes the 1-tick first pizza bite, 2-tick later bite, and standard 3-tick attack delay. Those observations justify the simulator's state/event capabilities, but specific timings remain **unavailable** in this snapshot until extracted into individually verified mechanic records and golden tests.

## Disagreements and exclusions

- Calculator code is never a tiebreaker against an authoritative source or an experimental record.
- RuneLite and Histogram reveal client-observed timing, not direct server sequencing.
- At the time of this review no item, spell, projectile, protection-prayer, switch or movement record had been hand-entered, and the ruleset deliberately failed preflight for them rather than emit an untrustworthy ranking. See [`rulesets/README.md`](../../rulesets/README.md) for what has been verified since.
